# 九州秋楓漫旅 2026 行程小幫手 (Kyushu Autumn Mobile Web App)

專為 2026/11/14~11/21 九州賞楓自駕自由行量身打造的高質感日系極簡莫蘭迪風手機旅遊 Web App，整合行程時間軸、手繪互動地圖、分區美食景點導航、準備清單與最新退稅指南，並支援 LocalStorage 本地儲存與一鍵匯出單檔 HTML。

## 1. Overview & Core Concept

- **目標使用者**：2026 年 11 月赴日本九州賞楓自駕的旅客，需在手機上快速查閱每日行程、導航路線、備選餐廳、飯店設施亮點與即時清單。
- **設計風格**：日式極簡＋秋季楓葉莫蘭迪色調（柔和楓紅、暖褐、霧金、米白與灰綠），搭配圓角毛玻璃（Frosted Glass）卡片與微光澤陰影，打造如原生 iOS / Android App 般的精緻觸感。
- **核心價值**：
  1. **零連線焦慮**：全部資料儲存於瀏覽器 LocalStorage，支援自訂修改/新增/刪除行程與清單，並可導出單檔 HTML 隨身攜帶。
  2. **資訊全整合**：航班 CI198/CI199、7晚精選住宿亮點（南阿蘇拉維斯塔、黑川湯本莊、杉乃井、金鱗湖 David No Yakata 壽喜燒民宿、小倉皇冠宮、博多 Clio Court、熊本城景 And COMFY）、租車與退稅完整收錄。
  3. **分區導航與備用美食庫**：將いまきん食堂、あか牛丼いわさき、高千穂牛 和、由布まぶし 心、一蘭總本店等 20+ 間餐廳依地理區域完整歸類，隨時一鍵開啟 Google Maps。

## 2. User Experience & Visual Design

### 視覺色彩與設計規範
- **色彩計畫 (Autumn Morandi Palette)**：
  - 主畫布背景：`#FAF8F5` (和風和紙米白)，搭配頂部微漸層楓葉霧粉 `#F7EBE8`。
  - 主強調色 (Maple Red)：`#C86D56` (莫蘭迪楓紅，用於選中日期、主要按鈕與重要標記)。
  - 次強調色 (Ginkgo Gold)：`#D9A05B` (銀杏霧金，用於特別亮點與拍照建議)。
  - 輔助色 (Forest Sage & Slate)：`#6B8177` (深林苔綠) 與 `#4A5568` (低飽和炭灰文字)。
  - 容器表面：`rgba(255, 255, 255, 0.85)` 搭配 `backdrop-blur-md` 與細緻雙重描邊 `1px rgba(220, 210, 200, 0.5)`。
- **字體層級**：
  - 標題與日期：`Plus Jakarta Sans` / `Noto Sans JP`，搭配 `text-wrap: balance`。
  - 時間與數據：`font-mono tabular-nums`，保證時間對齊不晃動。
- **版面配置與觸控人體工學**：
  - 嚴格遵守自然拇指操作區（底部 40% 為常規操作區，導航列維持 56px 緊湊高度，不超過螢幕 15% 限制）。
  - 頂部為橫向滾動日期膠囊（含「行前」、「11/14 五」至「11/21 五」）。
  - 底部五大核心分頁導航：【行程】、【地圖】、【導航】、【清單】、【資訊】。

## 3. Key Product Decisions & Trade-Offs

1. **資料架構：LocalStorage + 初始資料種子**
   - *決定*：應用程式首次啟動時自動載入使用者提供的完整 8 天行程、7 間飯店、20+ 備用餐廳與行前檢核清單；旅客在旅途中隨意編輯或勾選皆即時寫入 LocalStorage，重新整理不丟失，並提供「重設為預設行程」保護機制。
   - *優點*：純前端、零伺服器成本、離線可用。
2. **單檔 HTML 匯出引擎**
   - *決定*：在【資訊】頁面內建「匯出單檔 HTML」功能，透過前端腳本將當前最新狀態與整套單頁 HTML 程式碼動態打包為可獨立開啟的 `.html` 檔案下載，完全滿足「Single File」離線分享需求。
3. **繪圖風格九州互動地圖**
   - *決定*：打造 SVG / Canvas 手繪向量互動地圖，精確標示福岡市、北九州小倉、中津/耶馬溪、別府、由布院、九重、阿蘇、南阿蘇、高千穗、熊本等大地標與景點圖釘，支援觸控雙指縮放 (Pinch-to-Zoom)、平移 (Pan) 與點選地點跳出詳細資訊浮層。
4. **即時天氣與楓葉狀態串接**
   - *決定*：透過 Open-Meteo 免費氣象 API 取得九州主要城市（熊本、阿蘇、別府、福岡）當前氣溫與天氣圖示，若處於離線狀態則顯示秋季歷史平均氣溫（10°C~18°C，早晚溫差大）與日式楓葉預報指標。

### 資料模型 (State Schema)
- `itinerary`: 陣列，儲存 11/14~11/21 每日的詳細景點、建議抵達時間、停留時間、注意事項、拍照建議時間與手法、Google Maps 搜尋關鍵字。
- `hotels`: 7 間住宿的詳細規格、地址、入住/退房時間、飯店設施亮點、必玩/必吃/必體驗項目。
- `backupPlaces`: 20+ 間備用餐廳，附帶區域分類、推薦招牌料理與一鍵導航。
- `checklists`: 分類檢核項目（重要文件、3C 設備、衣物穿搭、藥品個人用品），支援勾選與自訂新增。
- `memos`: 個人記事文字，具備正則表達式自動辨識網址並轉換為安全外連按鈕。
- `appSettings`: 存放使用者自訂樣式、匯率換算設定與快取。
